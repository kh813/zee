# POSIX.1-2017 vi / ex 仕様 準拠チェックリスト

本ドキュメントは、**POSIX.1-2017 (IEEE Std 1003.1-2017) `vi` および `ex` ユーティリティ仕様**に対する **zee** の実装状況および今後の実装ロードマップを管理するチェックリストです。

実装が完了したものには `[x]` を付与し、バージョンとともに記録します。

---

## 1. モード遷移 (Modes)

| 状態 | コマンド / 機能 | 説明 | 実装状況・備考 |
| :---: | :--- | :--- | :--- |
| [x] | **Normal Mode** | コマンド待機モード（初期状態または `<Esc>` で遷移） | 全機能の基盤 |
| [x] | **Insert Mode** | テキスト挿入モード（`i`, `a`, `o` 等で遷移） | |
| [x] | **Visual Mode** | 選択モード（`v`, `V`, `Ctrl-V`） | Vim互換拡張 |
| [x] | **Ex Command Mode** | `:` 入力による最下行 Ex コマンドライン | 2行レイアウトで常時状態可視化 |
| [ ] | **Replace Mode** | `R` 入力による上書きモード | 未実装 |

## 8. zee 独自・現代的拡張 (Modern Extensions)

POSIX 仕様にはない、日本語環境や現代的 GUI/TUI エディタのための独自機能です。

| 状態 | 機能 | 説明 |
| :---: | :--- | :--- |
| [x] | **IME キー自動正規化** | 日本語入力オン状態での全角文字（`っ` → `dd`、`い` → `i`、全角コロン `：` → `:` など）をノーマルモードで透過的に解釈 |
| [x] | **CJK IME 状態検出** | macOS Carbon TIS API / Win32 / Linux を通じたゼロオーバーヘッド IME 状態判別 |
| [x] | **IME 追従アンダースコアカーソル** | Insert モード時に IME オンならオレンジ色アンダースコア `_` 描画＆ステータス `INSERT [あ]` バッジ連動 |
| [x] | **2行ステータス＆コマンドバー** | 上行にファイル・カーソル情報、下行に Ex コマンドライン＆モードメッセージ（`-- INSERT --` 等）を表示 |
